| 2026-11-11 | **PRD §13.1 decided by the maintainer:** Dart `int` → `int32_t`, `double` → `float`, `bool` → `bool` on every target. Sized `Uint8`/`Uint16`/`Int16` extension types in `package:unodar` map to `uint8_t`/`uint16_t`/`int16_t`. | One `int` width on Uno and ESP32 keeps programs portable, and 32 bits covers `millis()`-style values. | 2026-11-11 | Sized types are `extension type const Uint8._(int) implements int` with a wrapping `const Uint8(int v)` constructor. Reading widens to `int`; arithmetic yields `int`; storing back needs an explicit `Uint8(...)`. | The Dart side is real, executable, and tested, and it wraps exactly like the C++ conversion. | 2026-11-11 | `/` on ints is **implemented** as `float(a) / float(b)` (a `double` result, as in Dart), not rejected. | Dart's type checker already forbids storing the result in an `int` (E007, suggesting `~/`), so the C mistake of truncating division cannot happen silently. Precision is the documented `double` → `float` deviation. |
| 2026-11-11 | `~/` on ints compiles to C++ `/`; `%` on ints compiles to a `constexpr unodar_mod(a, b)` helper with Dart's non-negative result, emitted only when used. `%`/`~/` on doubles are rejected (E002). | Both C++11 and Dart truncate `~/` toward zero. | 2026-11-11 | The IR holds expression trees without parentheses; the emitter inserts them from C++ precedence and associativity. | The Dart parser's tree is the authority, so the output regroups correctly even where Dart and C++ precedence tables differ. |
| 2026-11-11 | Every `int` operation is computed in `int32_t`: when both operands would be narrower than 32 bits in C++ (literals and sized values on the 16-bit-`int` Uno), the emitter widens one with an `L` suffix or `int32_t(...)`. | 2026-11-11 | All-constant subexpressions are evaluated at compile time with Dart semantics; any intermediate value outside `int32_t`, or a constant division by zero, is E010. | 2026-11-11 | Assignments, `++`, and `--` are statements only (plus `for` updaters). | 2026-11-11 | `==`/`!=` between a `bool` and a number is E009. | Dart: never equal. C++: `true == 1`. |
